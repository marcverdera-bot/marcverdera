# Marc Verdera — Portfolio

Static site. No build step. Deployed on Vercel from this repo; every push to `main` redeploys.

- `index.html` — home
- `case-studies/` — four case studies
- `css/style.css` — shared styles (the home page carries its own inline copy)
- `vercel.json` — clean URLs (`/about` instead of `/about.html`)
